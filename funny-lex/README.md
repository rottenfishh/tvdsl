# HW1. Лексер Funny на Python: регулярки → НКА → ДКА → минимальный ДКА

## Запуск

Нужен только Python 3 (ничего устанавливать не надо).

```sh
python3 lexgen.py               # шаги построения, размеры, тесты; сохраняет funny_dfa.json
python3 lexgen.py program.fun   # то же самое + разбивает program.fun на токены (можно несколько файлов)
```
На Windows вместо `python3` пишите `python` (или `py`).

## Что внутри `lexgen.py` (разделы идут по порядку алгоритма)

1. `TOKENS` — список регулярок (приоритет = порядок в списке).
2. `NFA`, `RegexParser`, `build_nfa` — регулярка → НКА (Томпсон).
3. `build_dfa` — НКА → ДКА (построение подмножеств).
4. `minimize` — минимизация Хопкрофта.
5. `match`, `lex` — как пользоваться таблицей.
6. `export_table` — запись таблицы в `funny_dfa.json`.
7. `TESTS`, `expected_single_char`, `run_tests` — тесты.

## Результат

- `funny_dfa.json` — итоговая таблица: `start`, `trap`, `tokens`, `accept[состояние]`,
  `next[состояние][байт]`.
- Токены — по спецификации языка `funny.ru.md` из репозитория курса (nsu-fit/TVDSL) плюс то, что требует HW1
  (`function`, `length`, идентификаторы с `_`). Всего 49 токенов.
- Размеры: НКА 305 состояний, ДКА 127, минимальный ДКА **123** (с ловушкой).
- Ловушка: состояние 0. Не-ASCII байты ведут в неё из любого состояния, кроме тела комментария.
- Тесты: 134 теста + проверка каждого из 256 байтов, на ДКА до и после минимизации.
- Все 42 примера из `project/examples` курса разбираются без ошибок, кроме
  `step12/good_formulas_sorted.funny`: там импликация записана юникодной стрелкой `→` вместо `->`.

## Как добавить тест

Допишите строку в список `TESTS`:

```python
("match", "05", "BAD_INT"),
("lex", "if(a<=b)", "KW_IF LPAREN IDENT LE IDENT RPAREN"),
```
